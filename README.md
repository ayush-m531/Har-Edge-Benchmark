# Human Activity Recognition (UCI HAR Benchmarking)

This project benchmarks different deep learning models (MLP, CNN, LSTM, CNN-LSTM) 
on the [UCI HAR Dataset](https://archive.ics.uci.edu/ml/datasets/human+activity+recognition+using+smartphones).

## Models Implemented
- Multi-Layer Perceptron (MLP)
- Convolutional Neural Network (CNN)
- Long Short-Term Memory (LSTM)
- CNN-LSTM Hybrid

## Performance Metrics
For each model, we report:
- Accuracy
- Precision
- Recall
- F1-score
